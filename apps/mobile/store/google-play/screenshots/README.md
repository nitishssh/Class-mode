# Screenshot capture

Capture screenshots from a release-mode Android preview build using synthetic pilot data. Do not
use Expo Go, debug menus, personal accounts, real student names, or real phone numbers.

Required phone shots:

1. Teacher home with today's classes and marking status.
2. Attendance roster with present/absent controls and sync state.
3. Parent child summary with today's attendance.
4. Parent attendance history and fee summary.
5. Principal live attendance dashboard.
6. School fee overview/reminder workflow.

Use one consistent Android device size accepted by Play Console, keep system bars clean, and check
that no toast, keyboard, loader, or notification banner obscures content. Store final PNG files in
this directory only after a release owner reviews the synthetic data and listing claims.
