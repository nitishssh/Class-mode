# Startup Programs & Credits Pipeline

Free/no-equity programs worth a solo founder's time, ordered by expected value ÷ effort. Rule: applications are ops time (the ~20% budget), never displace school-facing work. Update `Status` as you go; one application per week is a sane pace.

## Apply now (high value, low effort, no equity)

| Program                                                                                       | What you get                                                                                                                                                                | Why us / eligibility                                                                                                                 | Effort              | Status |

## Application kit (write once, reuse everywhere)

Keep in `docs/dashboard/application-kit.md` when written: 50-word and 200-word product descriptions, problem statement (from the design doc), traction paragraph (pilot school + honest metrics from the latest snapshot), founder bio, ask. Every program form is a remix of these five blocks.

**Sequencing note:** Founders Hub first (pays the live Azure bill), entity registration + DPIIT second (unlocks the India stack: tax, SISFS, AWS-via-Startup-India), AI credits third (kills the Gemini quota problem the day-14 precondition worries about).
