# 📐 Technical Design: Native Study Arena Engine

This design outlines the migration of the multi-agent logic into the PersonalLearningPro tech stack.

## 🏗️ Architecture Overview

The existing "Bridge" architecture will be replaced by an "Integrated" architecture.

### Current (Bridge):
`Web UI` -> `PersonalLearningPro Server` -> `Study Arena Service (Iframe)` -> `Gateway` -> `LLM`

### Proposed (Integrated):
`Web UI (Native React)` -> `PersonalLearningPro Server (Internal Service)` -> `Study Arena Logic Module` -> `LLM (GPT-4o)`

## 💾 Data Models

We will extend the `MongoAIClassroom` schema to include the full lesson content, removing the need for an external `classroomId`.

```typescript
// shared/mongo-schema.ts
interface IClassroom {
  id: number;
  teacherId: number;
  topic: string;
  status: 'generating' | 'ready' | 'error';
  content: {
    agents: Agent[];
    scenes: Scene[];
    currentSceneIndex: number;
  } | null;
  createdAt: Date;
}
```

## 🖥️ Backend Components (Server)

1. **`server/services/study-arena/generator.ts`**:
   - Handles the recursive generation of lesson plans, slides, and quizzes.
   - Uses `server/lib/prompts/study-arena/` for specialized agent personas.
2. **`server/services/study-arena/orchestrator.ts`**:
   - Manages message passing between agents (Teacher, Student, User).
   - Injects "interactive moments" into the lesson stream.
3. **`server/routes/ai-classroom.ts`**:
   - Exposes streaming endpoints (SSE) for real-time classroom updates.

## 🎨 Frontend Components (Client)

1. **`client/src/components/ai-classroom/player/Player.tsx`**:
   - The main controller for the interactive experience.
2. **`client/src/components/ai-classroom/display/`**:
   - `SlideContainer.tsx`: Renders markdown/images.
   - `QuizContainer.tsx`: Renders interactive questions with AI feedback.
   - `SimulationContainer.tsx`: Renders sandboxed HTML/JS (using an `iframe` with blob/srcdoc for safety).
3. **`client/src/components/ai-classroom/agents/`**:
   - `AgentStage.tsx`: Visualizes all active agents.
   - `AgentVoice.tsx`: Hooks into existing TTS services.

## 🔄 State Management

- **Persistence**: MongoDB for long-term storage of generated classrooms.
- **Session State**: React Context for tracking the current scene and agent dialogue within a live session.
- **Real-time**: We will upgrade the existing `server/routes/ai-classroom.ts` to push updates via SSE (Server-Sent Events) during the generation phase.

## 🛠️ Security & Sandboxing

- **Simulations**: HTML/JS simulations generated by AI must be rendered in a sandboxed `iframe` with `sandbox="allow-scripts"` to prevent access to the main app's cookies or DOM.
